# Yahia PS4 File Installer 1.53

هذه نسخة تجريبية من تطبيق PS4 بصيغة PKG. ملفات تجربة 1.53 مضمّنة داخل الحزمة: `GTXMOD153.prx` و`plugins.ini` ومحتويات مجلد `GTX`.

## سلوك التطبيق

- قائمة الإصدار تعرض 1.53، ومن قائمة إضافية 1.56 و1.57. الإصداران 1.56 و1.57 فارغان حاليًا ويعرض اختيارهما «لا توجد ملفات لهذا الإصدار داخل التطبيق».
- قبل النسخ، يفحص التطبيق وجود موارد 1.53 داخل الحزمة ويطلب تأكيد التثبيت.
- الخطوة 1 تنسخ `GTXMOD153.prx` إلى `/data/GoldHEN/plugins/GTXMOD153.prx`.
- الخطوة 2 تستبدل `/data/GoldHEN/plugins.ini` بمحتوى الملف المرفق.
- الخطوة 3 تنسخ محتويات مجلد `GTX` إلى `/data/GTX/`.
- عند استبدال ملف موجود، ينقله التطبيق أولًا إلى اسم احتياطي بصيغة `.bak.<timestamp>.<number>`، ثم يكتب الملف الجديد. تعرض شاشة النتيجة نجاح أو فشل كل خطوة على حدة.

## الاختبار

ثُرجم البرنامج باستخدام OpenOrbis Toolchain 0.5.4، وبُنيت الحزمة محليًا. جرى التحقق من صحة بنية PKG وبصماته واستخراج الملفات المضمّنة بنجاح. لم يُختبر تشغيل التطبيق أو الكتابة إلى `/data` على جهاز PS4 فعلي بعد؛ يجب اختبار ذلك على جهاز المستخدم المعدّل مع تفعيل HEN.

ثبت PKG بالطريقة المعتادة على الجهاز المعدّل من Debug Settings → Game → Package Installer. قبل التأكيد، احتفظ بنسخة من بياناتك المهمة. ملفات PRX تُحمّل كإضافة تنفيذية عند تشغيلها بواسطة GoldHEN، لذا ثبت فقط ملفات تثق بمصدرها. إذا فشلت خطوة، أرسل صورة رسالة النتيجة أو رمز الخطأ.
