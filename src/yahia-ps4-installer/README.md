# GTXMOD Menu

تطبيق PS4 بصيغة PKG باسم **GTXMOD Menu**، يستخدم صورة GTX المرسلة كأيقونة، ويعرض واجهة رسومية داكنة بلمسات حمراء وصور جانبية وقائمة إصدارات عمودية.

## التحكم والواجهة

- تظهر الإصدارات 1.53 و1.56 في قائمة عمودية، وكلاهما يحتوي ملفات فعلية داخل الحزمة.
- الأسهم ↑/↓ للتنقل، و**X للتأكيد/الاختيار**، و**O للرجوع**؛ لا يعتمد الاختيار على أزرار حوار النظام أو إعداد ترتيب X/O فيه.
- عند اختيار 1.53 أو 1.56 تظهر شاشة «الملفات جاهزة» وزر تثبيت، وتستخدم كل نسخة ملفاتها الخاصة.
- تعرض الواجهة صورة القناة الجانبية كاملة بمحتوى الذئب واسم القناة والبايو والرابط والإحصائيات، ويظهر عنوانا GTXMOD MENU وPS4 FILE INSTALLER باللون الأحمر.
- تعرض شاشة نتيجة التثبيت العنوان «نتيجة التثبيت» فقط، وتظهر حالة كل خطوة «نجح» باللون الأخضر عند نجاحها أو «فشل» باللون الأحمر.
- بعد التثبيت تعرض الواجهة نجاح أو فشل كل خطوة على حدة.

## مسارات التثبيت

1. `GTXMOD153.prx` إلى `/data/GoldHEN/plugins/GTXMOD153.prx`؛ إذا كان الملف موجودًا يحذفه التطبيق ثم يثبت النسخة الجديدة.
2. استبدال `/data/GoldHEN/plugins.ini` بالملف المرفق مباشرةً؛ لا يتوقف التثبيت بسبب وجود ملف قديم بنفس الاسم.
3. نسخ محتويات `GTX` إلى `/data/GTX/` مع استبدال الملفات الموجودة بنفس الأسماء.

## ملفات الإصدار 1.56

يحتوي المسار `payload/1.56/` على `GTXMOD156.prx` و`plugins.ini` ومجلد `GTX`.
عند اختيار 1.56 يثبت التطبيق:

1. `GTXMOD156.prx` إلى `/data/GoldHEN/plugins/GTXMOD156.prx`.
2. `plugins.ini` إلى `/data/GoldHEN/plugins.ini`.
3. محتويات مجلد `GTX` إلى `/data/GTX/`.

ويستبدل الملفات الموجودة بنفس الأسماء مباشرةً.

## البناء والاختبار

يُبنى المشروع باستخدام OpenOrbis Toolchain 0.5.4 وGitHub Actions. يتضمن PKG ملف الصورة والخطوط والأصول اللازمة للواجهة. لم يُختبر تشغيل الواجهة أو الكتابة إلى `/data` على جهاز PS4 فعلي؛ اختبر على جهازك المعدّل مع تفعيل HEN، واحتفظ بنسخة من البيانات المهمة. ثبت PKG بالطريقة المعتادة من Debug Settings → Game → Package Installer، وثبت فقط ملفات PRX التي تثق بمصدرها.
