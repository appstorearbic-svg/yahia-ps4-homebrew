# GTXMOD Menu

تطبيق PS4 بصيغة PKG باسم **GTXMOD Menu**، يستخدم صورة GTX المرسلة كأيقونة، ويعرض واجهة رسومية داكنة بلمسات حمراء وصور جانبية وقائمة إصدارات عمودية.

## التحكم والواجهة

- تظهر الإصدارات 1.53 و1.56 و1.57 دائمًا في قائمة عمودية.
- الأسهم ↑/↓ للتنقل، و**X للتأكيد/الاختيار**، و**O للرجوع**؛ لا يعتمد الاختيار على أزرار حوار النظام أو إعداد ترتيب X/O فيه.
- عند اختيار 1.53 تظهر شاشة توفر الملفات وزر تثبيت؛ اختيار 1.56 أو 1.57 يعرض أن ملفاتهما غير متاحة حاليًا.
- بعد التثبيت تعرض الواجهة نجاح أو فشل كل خطوة على حدة.

## مسارات التثبيت

1. `GTXMOD153.prx` إلى `/data/GoldHEN/plugins/GTXMOD153.prx`.
2. استبدال `/data/GoldHEN/plugins.ini` بالملف المرفق؛ يحفظ التطبيق الموجود أولًا كنسخة `.bak.<timestamp>.<number>` ثم يثبت الجديد.
3. نسخ محتويات `GTX` إلى `/data/GTX/`.

## البناء والاختبار

يُبنى المشروع باستخدام OpenOrbis Toolchain 0.5.4 وGitHub Actions. يتضمن PKG ملف الصورة والخطوط والأصول اللازمة للواجهة. لم يُختبر تشغيل الواجهة أو الكتابة إلى `/data` على جهاز PS4 فعلي؛ اختبر على جهازك المعدّل مع تفعيل HEN، واحتفظ بنسخة من البيانات المهمة. ثبت PKG بالطريقة المعتادة من Debug Settings → Game → Package Installer، وثبت فقط ملفات PRX التي تثق بمصدرها.
