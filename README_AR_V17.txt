GTXMOD Mod Installer PS4 - V17

أضيفت في هذا الإصدار معلومات مباشرة أثناء تنزيل المود. يعرض التطبيق نسبة الإنجاز من 0% إلى 100%، وسرعة التنزيل الحالية بوحدة B/s أو KB/s أو MB/s، والوقت المتبقي التقديري بصيغة دقائق:ثوانٍ.

الحساب يعتمد على البيانات التي استلمها التطبيق فعلًا والزمن المنقضي منذ بداية التنزيل. لذلك يتغير الرقم تلقائيًا إذا أصبحت شبكة الإنترنت أسرع أو أبطأ. مثال: SPEED 500 KB/s وETA 15:00، ثم إذا ارتفعت السرعة إلى 1.00 MB/s ينخفض الوقت المتبقي تدريجيًا.

المؤشر تقديري وليس وعدًا ثابتًا؛ لأن MediaFire أو شبكة PS4 قد تغيّر السرعة أو توقفها مؤقتًا. عند عدم وصول بيانات كافية يظهر الوقت بعد بدء القياس، وتبقى وظيفة الإلغاء بزر دائرة كما هي.

لم تتغير وظائف جلب المنشورات أو الأكواد أو MediaFire أو التثبيت الذكي أو اكتشاف dlc.rpf وvehicles.rpf أو سجل installed.db أو الحذف وتعديل dlclist.xml. التغيير هو إضافة قياس وعرض السرعة والوقت داخل شاشة التنزيل.

البناء يتم عبر build-mod-installer.yml بالطريقة نفسها، والـ artifact هو GTXMOD-Mod-Installer-PS4. يجب اختبار PKG على PS4 بعد نجاح GitHub Actions.
